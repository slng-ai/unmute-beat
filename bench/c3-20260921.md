# C3 implementation evidence — 2026-09-21

C3 history/projection is implemented and passes the offline and live text checks.
This does not close the POC's audio acceptance, native comparison, or the separate
Gemini 3.1 conversational issues recorded in the recovery report.

- Canonical caller turns and speech segments have stable IDs. Submitted text,
  generated text and runtime playback estimates remain distinguishable. Playback
  changes the request projection, leaving business receipts and protocol intact.
- Typed `TemplateStr` instructions re-render named values for each request.
  `messages` includes fixed/model speech once; `reset` hides earlier context
  without deleting it or breaking the active tool loop. Orphan tool exchanges
  are removed from subsequent requests.
- Prerequisite returns restore the saved owner context with an application-owned
  completed/unserved status. Child conversation remains in the transcript/audit;
  abandoned work is not restored as pending work.
- Native task cancellation retains SDK messages, including completed tool
  results. Runtime input never received by an SDK run is still carried forward.
- Pipecat response frames carry run identity before speech begins. Playback
  callbacks bind to that run's segment IDs, including fixed speech. Unframed
  TTS is reconciled only when exactly one pending segment is identifiable.
  This is a runtime transcript estimate, not client playout measurement.

tool/output definitions and settings across a state update. It exercises the
core and adapter, repeated reset projections, completed/unserved returns, fixed
and model playback prefixes, late/ambiguous callbacks and native cancellation.

tool result left requests ending with an assistant message. Google rejected
them with HTTP 400; an empty trailing request did not help. Speech now shares its
producing response, preserving the following tool result. That sweep is retained
in [initial JSONL](c3-evidence/initial-failed.jsonl) and [log](c3-evidence/initial-failed.log).
